# Sito-vetrina-CyberSecurity

Istituto d'Istruzione Superiore "Guglielmo Marconi" Nocera Inferiore

Sito Vetrina CyberSecurity – Progetto di Diploma

Progettazione e sviluppo di un sito web statico responsive dedicato alla sensibilizzazione e divulgazione sui temi della sicurezza informatica.

Tecnologie: HTML5, CSS3, JavaScript, Bootstrap, Git

Obiettivo: Creare un'interfaccia chiara ed essenziale per la fruizione di contenuti informativi sulle minacce informatiche e le buone pratiche di protezione dati.
